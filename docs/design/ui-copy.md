# UI copy

The user requires a minimal interface. Text must help identify data, choose an action or understand an outcome.

- Use one screen title. Omit welcome copy and introductions that repeat the title, fields or buttons.
- Keep labels and actions short and specific: “Monthly spend”, “Auto-renew”, “Create account”.
- Show currency and billing period with amounts; avoid repeating them in adjacent captions.
- Keep empty states to one short line with an existing action nearby.
- Show explanations where needed: field errors, threshold settings, estimated savings, partial data, deletion effects and uncertain saves.
- Use short recommendation previews; keep the full reason on the detail page.
- Preserve accessible names even when visible copy is reduced. Do not replace clear actions with ambiguous icons.
- Keep headers free of back arrows. Use Android Back/gestures.

Applied in the 7 October copy pass: redundant Auth/form/Reminders introductions, currency captions, provider IDs and static Profile explanations removed. Data contracts and validation remain unchanged.
